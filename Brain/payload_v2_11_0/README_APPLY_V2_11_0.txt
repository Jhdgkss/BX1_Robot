ROBOT BRAIN V2.11.0 - PERSONALITY PROJECTS

PATCH INSTALL
1. Close Robot Brain.
2. Extract the patch ZIP.
3. Run APPLY_BX1_BRAIN_V2_11_0.bat.
4. If asked, enter the folder containing main_pyqt.py.
5. Start Robot Brain normally.
6. Open Robot > Identity / Personality > Open Personality Studio.

FULL PROJECT
The full V2.11.0 ZIP is already updated and does not require the patch BAT.

VOICE LAB
Each personality now has its own Dot.TTS Voice Lab namespace. If the shared
Dot.TTS service was already running during the update, press Stop Voice Service
once and restart it so the updated Lab page is loaded.

BACKUPS
The patch creates a timestamped backup inside the target project's backups folder.
