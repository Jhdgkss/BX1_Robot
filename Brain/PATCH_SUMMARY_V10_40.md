# BX1 Robot Body v10.40 patch summary

## One permanent microphone owner

The UNO Q Linux side now opens the ALSA microphone once and publishes 20 ms PCM frames to the level meter, dynamic wake detector, Production STT test and normal conversation capture. Normal operation no longer stops one `arecord` process to start another.

All endpointed captures have bounded start and maximum-utterance timeouts. The wake detector overlaps adjacent short grammar windows by 600 ms to avoid losing a phrase at a window boundary.

## Brain-owned name and wake phrases

The Body polls `GET /api/body_profile`, caches the last valid profile and uses the Brain-provided robot name, wake phrases and sensitivity. Local constrained Vosk grammar recognition performs wake detection; Brain Faster-Whisper still performs the full command transcription.

The Speech Input page displays the Brain-owned name and phrases and includes **Sync Brain profile now**.

## Queued speech stored on UNO Q

Wake acknowledgements, waiting phrases and the sleep acknowledgement are generated by the desktop Brain and downloaded to the UNO Q local cue cache. Downloads are atomic and verified using SHA-256. Edited wording invalidates any older cached file immediately.

The Brain owns phrase wording and first/repeat/maximum timing. The Body owns local playback, endpointing, speaker guards and safety switches.

## MCU status

This patch does not compile, upload or modify the MCU sketch. The working v10.39 RouterBridge, Modulino Movement, quiet-servo mode, addressable LEDs and disarmed wheel scaffolding are preserved.
